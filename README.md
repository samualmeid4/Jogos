# 🕹️ Coleção de Jogos em Python

Repositório de jogos clássicos desenvolvidos em **Python**, demonstrando lógica de programação, controle de estado, renderização gráfica e manipulação de eventos de teclado.

---

## 🎮 Jogos Inclusos
* **Snake Game:** Implementação do clássico jogo da cobrinha com contagem de pontuação dinâmica, colisão e controle direcional.

---

## 🛠️ Tecnologias
* **Python 3**
* **Pygame / Turtle / Standard Library**

---

## 🚀 Como Executar
```bash
cd "jogos/snake game"
python main.py
```
